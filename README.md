# Saffi — متجر إلكتروني (Next.js + Tailwind)

متجر إلكتروني كامل مبني بـ Next.js 14 (App Router) و Tailwind CSS، بالعربي وباتجاه RTL.

## التشغيل

```bash
npm install
npm run dev
```

افتح المتصفح على `http://localhost:3000`

## الصفحات

**عامة:**
- `/` — الصفحة الرئيسية، عرض كل المنتجات مع أزرار "أضف للسلة" و"اشترِ الآن".
- `/checkout` — السلة وفورم بيانات التوصيل (الاسم، الهاتف، المحافظة، العنوان).

**الإدارة (محمية بكلمة مرور):**
- `/admin` — جدول الطلبات + إدارة المنتجات (تعديل/حذف).
- `/admin/add` — إضافة منتج جديد.
- `/admin/edit/[id]` — تعديل منتج موجود.

رابط الإدارة **غير ظاهر** في أي مكان بواجهة العميل — للوصول له لازم تكتب `/admin` يدويًا في المتصفح.

## كلمة مرور الإدارة

الافتراضية هي: **010101**

لتغييرها، أنشئ ملف `.env.local` في جذر المشروع:

```
ADMIN_PASSWORD=كلمة_مرور_جديدة
```

## تخزين البيانات

المشروع دلوقتي بيستخدم **Upstash Redis** (قاعدة بيانات سحابية مجانية) لتخزين المنتجات والطلبات، عشان أي منتج تضيفه يظهر فورًا على كل الأجهزة والزوار — مش بس على الجهاز اللي أضفته منه.

لو المتغيرات دي مش موجودة (زي أول تشغيل على جهازك بدون إعداد)، المشروع بيرجع تلقائيًا لملف `data/db.json` المحلي — ده بيشتغل كويس للتجربة على جهازك بس، لكنه **مش هيشتغل صح على Vercel** لأن نظام الملفات هناك مؤقت (ephemeral) ومنفصل بين كل جهاز/زيارة — وده بالظبط سبب المشكلة اللي كانت بتحصل: المنتج بيتضاف على السيرفر اللي استقبل الطلب بس، مش على كل النسخ.

### إزاي تفعّل Redis (5 دقائق، مجاني بالكامل)

1. اعمل حساب مجاني على [upstash.com](https://upstash.com) (تقدر تسجل بحساب Google أو GitHub مباشرة).
2. من الداشبورد، اعمل **Create Database** ← اختار أي اسم واختار الـ Region الأقرب لك ← **Create**.
3. في صفحة قاعدة البيانات، هتلاقي تبويب **REST API** (أو "Details")، وفيه قيمتين محتاجهم:
   - `UPSTASH_REDIS_REST_URL`
   - `UPSTASH_REDIS_REST_TOKEN`
4. **للتجربة المحلية:** حط القيمتين في ملف `.env.local` في جذر المشروع:
   ```
   UPSTASH_REDIS_REST_URL=https://xxxxx.upstash.io
   UPSTASH_REDIS_REST_TOKEN=xxxxxxxxxxxx
   ADMIN_PASSWORD=كلمة_مرور_جديدة
   ```
5. **للنشر على Vercel:** روح لإعدادات المشروع على Vercel ← **Settings → Environment Variables** ← ضيف نفس المتغيرين (URL و Token) بالإضافة لـ ADMIN_PASSWORD، وبعدين اعمل **Redeploy**.

بمجرد ما المتغيرات دي تكون موجودة في بيئة الإنتاج، أي منتج تضيفه من لوحة الإدارة هيتخزن في Redis وهيظهر فورًا لأي حد بيفتح الموقع، من أي جهاز.

الكود في `lib/db.ts` مكتوب بحيث تقدر تستبدله لاحقًا بقاعدة بيانات تانية (PostgreSQL, MongoDB, Supabase...) من غير ما تلمس باقي التطبيق، لو احتجت.

## ملاحظات تقنية

- الصور بتتحفظ كـ base64 (data URL) جوه بيانات المنتج مباشرة، وبتتضغط تلقائيًا في المتصفح قبل الإرسال (عرض أقصى 700px) عشان الحجم يفضل معقول.
- نظام كلمة مرور الإدارة بسيط (مناسب لمشروع صغير/تجريبي) — كلمة المرور بتتبعت مع كل طلب تعديل عن طريق header، ومحفوظة في `localStorage` بعد تسجيل الدخول. لمشروع production حقيقي، الأفضل تستخدم نظام مصادقة أقوى (NextAuth مثلاً) مع جلسات وكوكيز آمنة.
- الألوان أبيض/أسود بالكامل، والخطوط: **Tajawal** (نصوص) و **Aref Ruqaa** (عناوين) من Google Fonts.

```
  admin/page.tsx            لوحة الإدارة

  admin/edit/[id]/page.tsx  تعديل منتج

components/                مكونات React (Header, ProductCard, ProductForm, ...)
lib/                        DB helper, types, إعدادات
data/db.json                قاعدة البيانات (ملف JSON)
```
